# GoBae Express Website

A mobile-friendly Next.js website for GoBae Express.

## Run locally
1. Install Node.js 18+.
2. In this folder run `npm install`.
3. Run `npm run dev`.
4. Open http://localhost:3000.

## Deploy to Vercel
1. Create a GitHub repository and upload these files.
2. Sign in to Vercel.
3. Choose Add New -> Project.
4. Import the GitHub repository.
5. Click Deploy.

## Important
The Messenger link currently uses `https://m.me/GoBaeExpress`. If your Facebook Page has a different username, change the `messenger` constant in `app/page.js`.
